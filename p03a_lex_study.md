# Practical 3(a) — Study of Lexical Analyzer Generator (LEX)

## What is LEX?
LEX (or its GNU version **FLEX**, "Fast LEX") is a tool that automatically generates a
**lexical analyzer (scanner)**. The programmer writes *regular expressions* with matching
*C actions*; LEX converts them into a C function `yylex()` which reads the input and
returns/prints tokens.

## How LEX works (theory in 10 lines)
1. The specification file has the extension `.l` (e.g. `scanner.l`).
2. LEX reads every regular expression and builds an **NFA** for it.
3. All NFAs are combined and converted into a single **DFA** (subset construction), which is minimised.
4. The DFA transition table is written into a C file called **`lex.yy.c`**.
5. `lex.yy.c` contains the function **`int yylex(void)`** that simulates the DFA on the input.
6. When several rules match, LEX uses **longest match** first; if two rules match the same length, the **rule written first** wins.
7. The matched text is available in the global string **`yytext`** and its length in **`yyleng`**.
8. Input comes from the file pointer **`yyin`** (default `stdin`), output goes to **`yyout`** (default `stdout`).
9. At end of input LEX calls **`yywrap()`**; returning 1 means "no more input", 0 means "continue with a new file".
10. Characters that match no rule are copied to the output by the default rule (`ECHO`).

## Structure of a LEX program
```
%{
   /* 1. DEFINITION SECTION
      C declarations, #include lines, global variables.
      Copied as-is to lex.yy.c */
%}
   name   regular-expression        /* named patterns, e.g.  digit [0-9] */

%%
   /* 2. RULES SECTION
      pattern      { C action }                                          */
{digit}+           { printf("NUMBER\n"); }

%%
   /* 3. USER SUBROUTINES SECTION
      main(), yywrap() and helper functions                             */
int main() { yylex(); return 0; }
int yywrap() { return 1; }
```

## Regular-expression operators used in LEX
| Pattern   | Meaning                               | Pattern  | Meaning                         |
|-----------|---------------------------------------|----------|---------------------------------|
| `.`       | any character except newline          | `r*`     | zero or more r                  |
| `[abc]`   | any one of a, b, c                    | `r+`     | one or more r                   |
| `[^abc]`  | any char except a, b, c               | `r?`     | zero or one r                   |
| `[a-z]`   | range                                 | `r{2,4}` | 2 to 4 repetitions              |
| `"text"`  | literal text                          | `r1\|r2` | r1 or r2                        |
| `^r`      | r at start of line                    | `r$`     | r at end of line                |
| `(r)`     | grouping                              | `r1/r2`  | r1 only if followed by r2       |
| `{name}`  | expansion of a named definition       | `<<EOF>>`| end of file                     |

## Important built-in variables, functions and macros
| Name                      | Purpose                                                         |
|---------------------------|-----------------------------------------------------------------|
| `yytext`                  | the text matched by the current rule                            |
| `yyleng`                  | length of `yytext`                                              |
| `yyin`, `yyout`           | input and output file pointers                                  |
| `yylex()`                 | the scanner function generated by LEX                           |
| `yywrap()`                | called at end of input (return 1 = stop)                        |
| `ECHO`                    | prints `yytext` to `yyout`                                      |
| `REJECT`                  | reject this match and try the next best rule                    |
| `BEGIN(state)`            | switch to a start condition                                     |
| `yymore()`                | append the next match to the current `yytext`                   |
| `yyless(n)`               | keep only the first n characters, push the rest back to input   |
| `unput(c)` / `input()`    | push a character back / read one character from the input       |
| `yyterminate()`           | stop the scanner and return 0 from `yylex()`                    |
| `yy_flush_buffer(buf)`    | discard the current input buffer (FLEX only)                    |

## Steps to compile and run
```
flex program.l              # generates lex.yy.c        (with classic lex:  lex program.l)
gcc lex.yy.c -o program     # compile (add -lfl if you did not define yywrap())
./program input.txt         # run
```

## Simple example (counts lines)
```
%{
#include <stdio.h>
int lines = 0;
%}
%%
\n      { lines++; }
.       { /* ignore */ }
%%
int yywrap() { return 1; }
int main() { yylex(); printf("Lines = %d\n", lines); return 0; }
```

## Advantages of using LEX
* Saves the time of hand-writing a scanner; the specification is short and readable.
* Easy to change — only the regular expressions need editing.
* Generated DFA code is fast and usually error-free.
* Works together with **YACC/Bison** (the parser generator): LEX supplies tokens through `yylex()`.
